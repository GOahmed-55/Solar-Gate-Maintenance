# نظام الصيانة – دليل التشغيل خطوة بخطوة

النظام عبارة عن 3 ملفات: `index.html` (الواجهة) و`config.js` (الإعدادات) و`schema.sql` (قاعدة البيانات).
البيانات تتخزن على **Supabase** (مجاني)، والصفحة تتنشر على **GitHub Pages** (مجاني).

## 1) إنشاء قاعدة البيانات (Supabase)
1. ادخل على supabase.com واعمل حساب (ممكن بحساب GitHub).
2. اضغط **New project**، اكتب اسم المشروع وكلمة سر لقاعدة البيانات (احتفظ بيها)، واختار أقرب منطقة (مثلاً Frankfurt).
3. بعد ما المشروع يجهز: من القائمة اليسار **SQL Editor** ← **New query** ← الصق محتوى `schema.sql` ← **Run**.
4. من **Authentication → Users → Add user → Create new user**: اكتب إيميل وكلمة مرور لكل موظف، واختار **Auto Confirm User**. (مفيش تسجيل مفتوح للناس، المستخدمين بتضيفهم انت بس.)
5. من **Project Settings → API** انسخ:
   - **Project URL**
   - **anon public key**
6. افتح `config.js` وحط القيمتين مكان الموجود.

> مفتاح anon آمن إنه يظهر في الصفحة، لأن الجدول محمي بـ Row Level Security ومحدش يقدر يقرأ أو يكتب إلا بعد تسجيل الدخول. **لا تضع أبداً مفتاح service_role في الملفات.**

## 2) النشر على GitHub Pages
1. ادخل github.com ← **New repository** ← اسم مثلاً `maintenance` ← اختار **Private** أو Public (Pages على الحسابات المجانية بيحتاج Public، فبما أن البيانات محمية بتسجيل الدخول مفيش مشكلة).
2. اضغط **uploading an existing file** وارفع `index.html` و`config.js` (و`schema.sql` و`README.md` لو حابب) ← **Commit changes**.
3. من **Settings → Pages**: في **Branch** اختار `main` و`/ (root)` ← **Save**.
4. بعد دقيقة هيظهر الرابط: `https://اسم-حسابك.github.io/maintenance/` وده رابط النظام. افتحه من أي جهاز.

## 3) الاستخدام
- **تسجيل جهاز**: املأ الفورم واحفظ. لما تكتب قيمة الصيانة بيتنسخ تلقائياً في الإجمالي (تقدر تعدله).
- **السجل**: بحث وفلترة وتعديل وحذف وتصدير Excel.
- **التقارير**: يومي / أسبوعي (من السبت للجمعة) / شهري، مع أزرار السابق والتالي، وملخص بالأرقام وتفصيل حسب الشركة ونوع الانفرتر وأسباب العطل، وطباعة أو حفظ PDF وتصدير Excel.
- **استيراد من Excel**: احفظ شيتك الحالي CSV UTF-8 وارفعه من تبويب الاستيراد.

## ملاحظات
- لازم يكون عمود "اسم الشركه" موجود في الشيت المستورد.
- النسخة المجانية من Supabase بتوقف المشروع لو ما استُخدمش أسبوع كامل، ويرجع بضغطة من لوحة التحكم. ولو النظام شغال يومياً مفيش مشكلة.
- خد نسخة احتياطية دورية: من تبويب السجل اضغط **تصدير Excel**.
